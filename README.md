# Pixel Art Soccer Player

This project is a simple HTML file that shows a small animated soccer player made with pixel art.

## What it does

- Creates a floating soccer player on the page
- Draws the character using a canvas
- Animates the player with simple movement
- Places the character randomly on the left or right side of the screen

## How to use it

1. Open the file named `soccer_player_in_pixel_art_on_the_web.html` in your browser.
2. The animation will appear automatically.
3. You can also paste the code into another HTML page if you want to use it in a website.

## Simple explanation

The code uses:
- HTML to create a container for the animation
- CSS to position the player on the screen
- JavaScript and canvas to draw and animate the soccer player

## How to use it in Elementor

If you want to use this animation in an Elementor page, follow these simple steps:

1. Open your Elementor editor.
2. Add an HTML widget to the page.
3. Copy the full contents of the file named `soccer_player_in_pixel_art_on_the_web.html`.
4. Paste it into the HTML widget.
5. Save and preview the page.

You can learn more about Elementor here: https://elementor.com/

If you want, you can also change the colors, size, or movement speed by editing the values near the top of the JavaScript code.
